# Spooky Cable - Quick Start Guide

## 🚀 Getting Started (5 Minutes)

### 1. Start the Server
```bash
cd C:\Users\sampc
python -m http.server 8000
```

### 2. Open Your Browser
Navigate to: **http://localhost:8000/tv**

### 3. Power On
Press **any key** to power on the TV

---

## 🎮 Essential Controls

| Key | Action |
|-----|--------|
| **1-9, 0** | Direct channel tuning (10 = press 1, then 0) |
| **↑ / ↓** | Channel up/down |
| **G** | Toggle picture-in-picture guide |
| **I** | Show info banner |
| **M** | Mute/unmute |
| **F** | Fullscreen |

---

## 📺 The Guide (Press 'G')

### First Press:
- Guide appears with **video in top-left corner**
- Ambient music plays in background
- Shows program listings for all channels

### Press Arrow Keys:
- Opens **interactive guide** overlay
- Navigate with ↑↓←→ keys
- Press **ENTER** to tune to channel
- Press **ESC** to return to guide

### Second Press of 'G':
- Returns to **full screen video**
- Music fades out

## 🎃 Quick Tips

### Want to Watch a Movie?
1. Press **6** (Disney Classics)
2. Press **I** to see what's playing
3. Press **F** for fullscreen
4. Enjoy!

### Want to Browse While Watching?
1. Press **G** once (PiP guide appears)
2. Use arrow keys to browse
3. Press **G** again when ready to return

### Want to See What's Coming Up?
1. Press **G** (PiP guide)
2. Press any arrow key (interactive guide)
3. Use → to see future time slots
4. Press **ESC** when done

## ⚡ Troubleshooting

### No Video Playing?
- Check that server is running on port 8000
- Verify media files are in `media/` folders
- Try changing channels with number keys

### No Sound?
- Press **M** to unmute
- Check system volume
- Guide music only plays on Channel 1 and in PiP mode

### Guide Not Showing?
- Make sure you're not on Channel 1
- Press **G** to toggle guide
- Press **ESC** if in interactive mode
